## Experiencia destacada

### 🏘️ [Hilding Ohlsson Propiedades](https://hildingohlsson.ar/) · Plataforma inmobiliaria *(en desarrollo)*
- **Desafío:** que buscar, consultar y gestionar propiedades sea simple tanto para clientes como para administradores.
- **Mi rol:** diseño y maquetación del frontend (home, ficha de propiedad, operaciones) e interfaces de login y autenticación para usuarios y admins. Integración con backend.
- **Stack:** Laravel · Filament · Livewire · Alpine.js · Tailwind CSS

### ☕ [Miel Tostadores](https://mieltostadores.com) · E-commerce y landing de café de especialidad
- **Desafío:** vender café de especialidad con una historia de marca fuerte, sin perder conversión en el checkout.
- **Mi rol:** UI de la tienda y del flujo de compra; panel de clientes (estado de pedidos, seguimiento, reembolsos); landing con storytelling y componentes interactivos con Alpine.js; integración con Mercado Pago.
- **Stack:** Laravel · Filament · Livewire · Alpine.js · Tailwind CSS · PostgreSQL · Docker

### 🧭 [Brújula Plutónica](https://brujulaplutonica.com) · Sitio y plataforma de contenidos y servicios
- **Desafío:** presentar contenido y servicios de astrología transpersonal con una estética propia y fácil de navegar.
- **Mi rol:** maquetación responsive y colaboración en la evolución del CMS personalizado en Filament.
- **Stack:** Laravel · Filament · Livewire · Tailwind CSS · Vite · MySQL · Docker

### 🏗️ [Constructora Atlántica](https://constructoraatlantica.com.ar/) · Rediseño web y dashboard de autogestión
- **Desafío:** un sitio de 2020 que no transmitía solidez de marca y un cliente que necesitaba gestionar sus proyectos de forma autónoma.
- **Mi rol:** liderazgo del rediseño visual y de navegación; participación en arquitectura y maquetación del dashboard.
- **Stack:** Laravel · Filament · Tailwind CSS · Alpine.js · Vite · PostgreSQL · Docker

### 📅 [turnitos.app](https://turnitos.app) · Frontend estratégico para SaaS de turnos
- **Desafío:** que reservar un turno sea rápido y claro para el usuario final, con lógica de negocio compleja por detrás.
- **Mi rol:** diseño y maquetación de la UI, componentes interactivos y vistas clave; coordinación con el backend en Laravel.
- **Stack:** Laravel · Livewire · Alpine.js · Tailwind CSS · Vite

### 🏢 [TreceAR](https://trece.ar) · Plataforma digital de la agencia
- **Desafío:** construir la principal herramienta de marketing y presentación de la agencia, que comunique nuestra filosofía de trabajo y demuestre capacidad técnica con una arquitectura sólida y escalable.
- **Mi rol:** desarrollo completo de la web con foco en la experiencia de usuario y el frontend. Diseñé la interfaz con Tailwind CSS, integré el formulario de contacto con Livewire y gestioné las microinteracciones y la navegación con Alpine.js, sobre una arquitectura Laravel con Filament.
- **Stack:** Laravel · Filament · Livewire · Alpine.js · Tailwind CSS · Vite · MySQL · Docker · GitHub

## Laboratorio de Aprendizaje & Proyectos Integradores

En estos proyectos aplico de forma práctica los conocimientos adquiridos en mis certificaciones, enfrentando desafíos reales de lógica, arquitectura y experiencia de usuario.

### 🔹 [Sara Figarra · Landing, panel y API](https://proyecto-integrador-adaitw.onrender.com) - Proyecto Integrador ADA ITW
* **Repositorio:** [proyecto-integrador-adaitw](https://github.com/aylenfrisoli/proyecto-integrador-adaitw)
* **Tecnologías:** Node.js 22, Express 5, TypeScript, MongoDB Atlas, Mongoose, Zod, JWT, React 19, Vite.
* **Descripción:** Sitio para una artista plástica con una landing pública de obras, productos y talleres, y un panel de administración desde el que ella carga y edita el contenido. Monorepo con una API REST (`backend/`) y un frontend en React (`frontend/`), deployados en Render.
* **Desafío:** Diseñar una arquitectura por capas con autenticación JWT, validación de datos con Zod, rate limit contra fuerza bruta y un flujo de carga de imágenes que sea simple para una usuaria no técnica.

### 🔹 [Buscador de Superhéroes](https://integrador-superhero-aylen-frisoli.vercel.app) - Proyecto Integrador
* **Repositorio:** [integrador-superhero-aylen-frisoli](https://github.com/aylenfrisoli/integrador-superhero-aylen-frisoli)
* **Tecnologías:** JavaScript, Vite.
* **Descripción:** Aplicación para buscar, filtrar y descubrir héroes del multiverso, con filtros por orden, letra, editorial, alineación, género y raza. Deployada en Vercel.
* **Desafío:** Combinar varios filtros en una misma búsqueda sin que la interfaz se sienta densa ni confusa.

### 🔹 [BiblioDivergente](https://github.com/aylenfrisoli/BiblioDivergente) - Proyecto de IA Generativa
* **Tecnologías:** IA Generativa, Prompt Engineering, Estrategia de Contenidos.
* **Descripción:** Un proyecto innovador donde exploro el potencial de la Inteligencia Artificial para la organización o recomendación de contenidos, integrando nuevas herramientas al flujo de trabajo digital.
* **Desafío:** Ofrecer una herramienta verdaderamente útil, accesible y adaptada para mentes neurodivergentes.

### 🔹 [Book API](https://github.com/aylenfrisoli/trabajo-practico-integrador-book-api) - Sistema de Gestión de Libros (Backend)
* **Tecnologías:** Node.js, Lógica de Servidor.

* **Desafío:** Estructurar una arquitectura limpia que separe la lógica de negocio de la presentación.
